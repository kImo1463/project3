This project is a dynamic e-commerce auction platform designed to replicate the core features of eBay. Users can list items for auction, place bids, and manage their listings and purchases. The system is built using Django and SQLite, offering a simple yet effective solution for online auctions.
Features

    User Registration & Authentication: Secure sign-in, sign-up, and account management for buyers and sellers.
    Item Listings: Sellers can list items for auction, including item descriptions, photos, and starting bids.
    Bidding System: Buyers can place bids on active auction listings. The system ensures the highest bid is tracked.
    Auction Countdown: Each auction has a countdown timer indicating when it will close, with real-time updates.
    Order Management: Winning buyers can view their purchased items and sellers can manage their sold items.
    Search & Filtering: Buyers can search for items by categories, keywords, or price range.

Technologies Used

    Django: A robust Python web framework used to build the back-end logic, handling user requests and data management.
    SQLite: A lightweight relational database engine used for storing user data, auction items, and bid information.
    HTML/CSS/JavaScript: Front-end technologies for creating an interactive and responsive interface.
    AJAX: Used for dynamic updates of bid values and countdown timers without page reloads.
    REST API: Used for handling item listings, bids, and user actions, making the site scalable and responsive.
